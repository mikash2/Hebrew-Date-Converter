# Hebrew Date Converter

A simple web application that converts Gregorian dates to Hebrew dates using the Hebcal REST API.

## Technologies
- Python
- Flask
- HTML and CSS
- Hebcal REST API

## Features
- Gregorian to Hebrew date conversion
- Server-side date validation
- Error handling for invalid input and API failures
- Hebrew right-to-left text support

## Installation and Usage

1. Clone the repository.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open http://127.0.0.1:5000 in your browser.
